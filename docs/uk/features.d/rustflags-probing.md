# Зондування RUSTFLAGS окремо за кожним прапорцем і архітектурою

- Кожен кандидат-прапорець зондується проти встановленого `rustc`; експортуються лише прапорці, які приймає інструментальний ланцюжок.
- Це робить образи переносними між версіями Rust та архітектурами CPU без ручного супроводу прапорців.
- amd64 цілиться в набір можливостей x86-64-v3; arm64 — у розширення Armv8.x для кожного покоління.
- Непідтримувані прапорці мовчки відкидаються й ніколи не ламають збирання.
- Повний механізм, файли прапорців і списки кандидатів за архітектурами: див. [динамічні прапорці компілятора](../flags.md).
