# Декларативне встановлення cargo зі списку залежностей

- Перелічіть crate-и для встановлення в одному файлі залежностей; кожна встановлюється `--locked`.
- Похідні образи успадковують той самий декларативний спосіб встановлення без додаткового налаштування.
